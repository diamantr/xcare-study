# X-CARE בעל פה

כלי לימוד לשינון הסכמה האחודה לטיפול בפצוע בודד (X-CARE), מילה במילה לפי הדף.

מצבים: עיון (עם מצב כיסוי), שליפה, השלמת מילים, סידור שורות.

תוספת: `terms.html` – שאלון אמריקאי על מילון המושגים (27 מושגים, בשני הכיוונים), עם רשימת מושגים לעיון.

פותחים את `index.html` בדפדפן, או דרך GitHub Pages. אין צורך בהתקנה. ההתקדמות נשמרת בדפדפן המקומי.
